# Problem Statement

## Problem

Teachers often keep student marks in notebooks or scattered spreadsheets. It takes time to work out averages and find the top student, and it is easy to make mistakes when entering or changing marks. There is also no quick way to check that a name was not already entered or that a mark was typed correctly.

## Scope

The project is a console application that:

- stores student names with marks for two subjects,
- lets the user add, view, search, update and delete records,
- calculates the class average for each subject and finds the topper,
- checks user input and shows clear error messages.

It does **not** include a graphical interface, user login, or permanent storage. Records exist only while the program is running.

## Target Users

- Teachers or teaching assistants who manage a small class
- Students learning Python who want an example of a modular menu-driven program

## High-Level Features

1. Add student
2. View all student reports
3. View class average
4. Find class topper
5. Search student
6. Update marks
7. Delete student
8. Exit

The code is divided into three functional modules (database, operations and analytics) plus a main file that connects them.
