# Problem Statement

## Problem

Many teachers, educators, and staff members in prestigious institutions have a very hectic job of managing the database of vast number of students and hence , mistakes are commonly made while adding, updating or deleting the data or it takes much more time than they have.

## Scope

The project is a helpful application that:

- stores student names with marks for two subjects,
- lets the user add, view, search, update and delete records,
- calculates the class average for each subject and finds the topper,
- checks user input and shows clear error messages.

It does **not** include a graphical interface, user login, or permanent storage. Records exist only while the program is running and will be lost when the program has been exited from.

## Target Users

- Teachers or teaching assistants who manage a small class or a faculty who has to simultaneously manage grades for more than 1 class.
- Non-Teaching staff who has to find the average marks and toppers of multiple classes without any help.

## High-Level Features

1. Add student
2. View all student reports
3. View class average
4. Find class topper
5. Search student
6. Update marks
7. Delete student
8. Exit

The code is divided into three functional modules (database, operations and analytics) plus a main file that connects them.
